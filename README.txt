ذاكر يا يونس! PWA
لتثبيت التطبيق من المتصفح: ارفع كل محتويات المجلد على موقع HTTPS، افتح الرابط على Chrome Android، ثم من القائمة اختر Install app / إضافة إلى الشاشة الرئيسية. افتح التطبيق أول مرة أونلاين وانتظر تحميل الملفات ثم استخدمه أوفلاين.
فتح index.html مباشرة يعمل للعب على بعض المتصفحات، لكن تثبيت PWA والعمل المضمون أوفلاين يحتاج HTTPS أو localhost.
التسجيلات الثلاثة هي ملفات ElevenLabs الأصلية للمستخدم، بدون استخدام speechSynthesis. الأزرار تشغل الملفات الكاملة، ولا ندّعي مطابقة كل سؤال بمقطع صوتي بعد.
