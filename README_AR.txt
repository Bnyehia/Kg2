ذاكر يا يونس! — نسخة Vercel PWA

1) ارفع محتويات هذا المجلد كما هي إلى مستودع GitHub، ثم اختر Import Project في Vercel.
2) Framework Preset: Other، Build Command: فارغ، Output Directory: فارغ، Root Directory: جذر المشروع.
3) افتح رابط HTTPS في Chrome على Android ثم اختر Install app.
4) افتح اللعبة مرة مع الإنترنت وانتظر اكتمال تنزيل ملفات الصوت قبل فصل الإنترنت.

ملاحظة مراجعة الصوت: تم تقسيم التسجيلات الثلاثة آلياً باستخدام الصمت وطول النص، والتسميات هي مطابقة تقديرية وليست محاذاة صوتية موثقة. راجع التسجيلات، خصوصاً المقاطع العربية، قبل نشرها للأطفال. يحتوي audio_map.json على أسماء العبارات والملفات لتصحيحها.
